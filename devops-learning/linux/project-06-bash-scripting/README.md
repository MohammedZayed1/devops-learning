# Project 06 - Bash Scripting & Automation

# Objective

The objective of this project is to learn the fundamentals of Bash scripting and automate common Linux administrative tasks. The project demonstrates how repetitive system operations can be simplified using shell scripts, a core responsibility of DevOps Engineers.

# Scenario
As a Junior DevOps Engineer, the operations team requested an automated daily server health report instead of manually executing multiple Linux commands every day.
The goal of this project was to develop Bash scripts capable of collecting system information, interacting with users, making decisions, and generating reports automatically.

# Tasks
- Create executable Bash scripts.
- Use the Bash shebang (`#!/bin/bash`).
- Work with variables.
- Accept user input using `read`.
- Implement conditional statements.
- Use loops to automate repetitive tasks.
- Execute Linux commands inside scripts.
- Generate a complete server health report.
- Save script output to text files.
- Generate timestamped reports.
- Use exit codes to indicate script success or failure.

# Project 1 - Linux Server Setup 

# Scenario 
Your company has rented a new Ubuntu server on AWS.
Your manager says:
	"Prepare the server so developers can start deploying applications."

# Objective 
Prepare a fresh Ubuntu server for development. 

# Tasks 
- Update package lists
- Upgrade installed packages 
- Check CPU, memory, and disk usage
- Install Git 
- Install Nginx 
- Start Nginx 

# Commands 
- apt update
	Refreshes package information.

- apt upgrade -y 
	Installs available updates.

- apt install git -y 
	Install git 

- apt install nginx -y 
	Install nginx 

- systemctl
	Used to manage Linux services.

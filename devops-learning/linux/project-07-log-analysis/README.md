# Project 07 - Linux Log Analysis & Text Processing

# Objective

The objective of this project is to develop practical skills in analyzing Linux log files using command-line text processing tools. The project focuses on extracting meaningful information from logs, identifying errors, generating reports, and troubleshooting application issues efficiently.

# Scenario

A production application begins returning errors, and users report that the service is unstable.

As the on-call DevOps Engineer, the objective is to investigate the application's log files, identify errors and warnings, summarize important events, and generate reports without modifying the application itself.

# Tasks

- Create and analyze sample application logs.
- Display log contents using different Linux utilities.
- Filter log entries by severity level.
- Count occurrences of errors and warnings.
- Search for specific application events.
- Extract structured information using `awk`.
- Modify log content using `sed`.
- Sort and summarized log entries.
- Generate dedicated error reports.
- Create an automated log summary using a Bash script.

# Project 03 - Linux File Management

# Scenario 
A new project named Inventory Management System is starting. Your manager asks you to prepare the project directory, organize files, create backups, and archive old logs.

# Objective
Preparing and maintaining the file system for an Inventory Management System application.

# Tasks
- Creat a professional project directory structure.
- Creat source code, configuration, log, and script files.
- Add sample content to project files.
- Read file contents using different Linux commands.
- Copy files and directories.
- Move and rename files.
- Search for files using `find`.
- Search file contents using `grep`.
- Compress project files using `tar`.
- Extract archived files.
- Check disk usage and available storage.
- Creat and verified symbolic links.

# Commands
= File & Directory Management
- `mkdir`
- `touch`
- `cp`
- `mv`
- `rm`
- `tree`
- `ls`

= Reading Files
- `cat`
- `less`
- `head`
- `tail`

= Searching
- `find`
- `grep`

= Archiving
- `tar`

= Disk Usage
- `du`
- `df`

= Links
- `ln -s`
